Этап 1. Проектирование

IPv4:
192.168.10.0/27

Маска:
255.255.255.224

Шлюз:
192.168.10.1

Диапазон:
192.168.10.1 - 192.168.10.30

Broadcast:
192.168.10.31

Причина:
/27 дает 30 рабочих адресов, что достаточно для 25 ПК.

Этап 2. Базовая настройка R1

Hostname:
R1

DNS lookup:
Отключен

Команды:
enable
configure terminal
hostname R1
no ip domain-lookup

Router: Cisco 1941

Hostname:
R1

DNS lookup:
Disabled

Пользовательская сеть:
192.168.10.0/27

Шлюз:
192.168.10.1

Этап 3. Настройка интерфейса LAN

Интерфейс:
GigabitEthernet0/0

Описание:
LAN_to_Switch

IP адрес:
192.168.10.1

Маска:
255.255.255.224 (/27)

Назначение:
Шлюз пользовательской сети

Команды:
interface g0/0
description LAN_to_Switch
ip address 192.168.10.1 255.255.255.224
no shutdown
